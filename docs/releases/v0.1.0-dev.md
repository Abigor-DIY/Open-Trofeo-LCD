# Open Trofeo LCD v0.1.0-dev

Development preview for early testers.

Open Trofeo LCD is a reverse-engineered Linux driver and Qt desktop application
for the Thermalright Trofeo LCD cooler display. This build is usable, but it is
still under active development. Expect UI changes, incomplete editor tools and
occasional regressions while packaging and the theme workflow are stabilized.

## Highlights

- Local backend for controlling the Trofeo LCD over USB.
- Qt GUI with Theme Gallery, Theme Designer and Animation Studio.
- Theme JSON renderer with system stats, MPRIS Now Playing widgets, gauges,
  volume/EQ elements and animated background tooling.
- Six polished bundled starter themes with full rendered previews:
  Heritage Duality, Matrix Green, Verdant Bloom, Wolfstorm Forge, Orbital Relay
  and Obsidian Pulse.
- Weather widgets with city search, current conditions, 7-day forecast and
  animated Meteocons-based icons.
- Now Playing widgets with cover placeholders, marquee title support and unified
  real-time/synthetic EQ rendering.
- Experimental Flatpak bundle and source-based portable package workflow.
- Initial DEB/RPM package skeletons for local distro packaging tests.
- GPL-3.0-only license for the project code, with third-party dependency license notes.

## Download

- Flatpak bundle:
  `open-trofeo-lcd-0.1.0-dev.flatpak`
- Portable source package:
  `open-trofeo-lcd-0.1.0-dev-portable.tar.gz`

Install locally:

```bash
flatpak install --user ./open-trofeo-lcd-0.1.0-dev.flatpak
flatpak run io.github.AbigorDIY.OpenTrofeoLCD
```

If Flatpak asks for runtime dependencies, install them from Flathub:

```bash
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak install flathub org.freedesktop.Platform//25.08
```

The Flatpak is still experimental. It uses broad development permissions for
USB access, local files and MPRIS media metadata.

## Install From Source

```bash
sudo apt install python3-venv python3-pip python3-usb python3-pil playerctl ffmpeg cava
scripts/setup_gui_venv.sh
sudo cp 99-trofeo-lcd.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger
scripts/run_trofeo_gui.sh
```

After installing the udev rule, unplug and replug the LCD.

## Known Limitations

- The Flatpak bundle is experimental and has not yet been validated on clean
  systems without the source checkout.
- DEB/RPM packaging is scaffolded, but dependency names and install behavior
  still need clean-VM validation before public binary packages are recommended.
- Some Theme Designer and Animation Studio tools are still being refined.
- High-FPS animated themes can stress USB transfer and LCD refresh.
- MPRIS media metadata depends on player support, for example Chromium,
  Spotify, VLC or other compatible players.
- Real-time Graphic EQ / Now Playing EQ uses host `cava`; without it the app
  falls back to synthetic EQ animation.
- Flatpak dependency sources are pinned in `packaging/flatpak/requirements.txt`,
  but the build still downloads wheels from PyPI. A stable Flatpak should use
  generated source entries with hashes.
