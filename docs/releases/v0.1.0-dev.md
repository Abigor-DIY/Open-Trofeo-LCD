# Open Trofeo LCD v0.1.0-dev

Development preview for early testers.

Open Trofeo LCD is a reverse-engineered Linux driver and Qt desktop application
for the Thermalright Trofeo LCD cooler display. This build is usable, but it is
still under active development. Expect UI changes, incomplete editor tools and
occasional regressions while packaging and the theme workflow are stabilized.

## Highlights

- Local backend for controlling the Trofeo LCD over USB.
- Qt GUI with Theme Gallery, Theme Designer and Animation Studio.
- Theme JSON renderer with system stats, MPRIS Now Playing widgets, gauges,
  volume/EQ elements and animated background tooling.
- Initial bundled theme set so the app is not empty after checkout.
- Development documentation for upcoming Flatpak/DEB/RPM packaging.

## Install From Source

```bash
sudo apt install python3-venv python3-pip python3-usb python3-pil playerctl
scripts/setup_gui_venv.sh
sudo cp 99-trofeo-lcd.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger
scripts/run_trofeo_gui.sh
```

After installing the udev rule, unplug and replug the LCD.

## Known Limitations

- Flatpak/DEB/RPM packages are not available yet.
- Some Theme Designer and Animation Studio tools are still being refined.
- High-FPS animated themes can stress USB transfer and LCD refresh.
- MPRIS media metadata depends on player support, for example Chromium,
  Spotify, VLC or other compatible players.
