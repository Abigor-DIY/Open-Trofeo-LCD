# Open Trofeo LCD v0.1.0-dev20260519

Development preview for Linux packaging and Trofeo LCD theme testing.

This release refreshes the current starter package after the Windows-capture
based backend and theme optimization work. It is still a development build, but
the Linux distribution path is now usable for local testing.

## Highlights

- Six bundled starter themes:
  Heritage Duality, Linux Matrix Green, Obsidian Pulse, Orbital Relay,
  Verdant Bloom and Wolfstorm Forge.
- Updated DEB packaging workflow for Ubuntu/PPA source builds.
- Updated Flatpak bundle with current app metadata and package exclusions.
- Native PyUSB backend remains the default runtime path.
- CAVA, OpenCV and Numpy are declared for current EQ and animation workflows.
- TRCC remains optional until it is packaged as a normal distro dependency.
- Large Windows captures and unused theme assets are excluded from release
  archives and Linux packages.

## Local Install

```bash
sudo apt install ./open-trofeo-lcd_0.1.0~dev20260519_all.deb
open-trofeo-lcd
```

```bash
flatpak install --user ./open-trofeo-lcd-0.1.0-dev20260519.flatpak
flatpak run io.github.AbigorDIY.OpenTrofeoLCD
```

After installing native packages, unplug and reconnect the LCD if udev rules
were updated.

## Known Limitations

- The Flatpak bundle is still experimental and uses broad development
  permissions for USB, home files, MPRIS and audio access.
- The DEB package is validated locally, but still needs clean Ubuntu VM testing
  before it should be treated as stable.
- Real-time EQ depends on host audio tooling and CAVA availability.
- Launchpad/PPA publishing requires a signed source upload.
